# Perona 👻
`Perona` foi criada com o intuito que qualquer pessoa consiga criar seus próprios script para `Mu Online`, sem a necessidade de saber sobre `Engenharia Reversa.`<br />
O projeto inteiro foi tipado para que possa facilitar a vida de quem for desenvolver os scripts. <br />
Atualmente a `Perona` está na sua versão `Alpha (0.1.0)`. <br />

Acesse o nosso [Discord](https://perona.fun/discord) e fique por dentro das atualizações e novidades.

# ATENÇÃO
Não tente lucrar vendendo `perona.exe`. Os scripts desenvolvidos pelos usuários podem ser comercializados* da maneira que os criadores dos scripts decidirem<br />
Por ser um projeto gratuito `>EU<` não garanto que eu irei continuar mantendo atualizado ou adicionando novas features no futuro. O projeto em sí também vai depender do feedback da comunidade. 
A `perona` em sí foi criado apenas para estudar a integração entre `Rust, Lua e Engenharia Reversa`.
* `perona` atualmente só tem suporte para versão `21.2.3.0 (Season 21 - Parte 2-3)` independente do emulador.
